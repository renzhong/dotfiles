# nvm
- `nvm default use` 使用默认的 node 版本
- `nvm install --lts` 安装长期固定版本
- `nvm list` 列出安装版本
- `nvm use` 使用 .nvmrc 中的版本

# fnm
cd project-a
echo "18" > .node-version
fnm install
fnm use
---
cd project-b
echo "22" > .node-version
fnm install
fnm use
